# 楊文霓 個人展示站

## 頁面清單
- index.html　首頁（主題、精選作品、最新展訊）
- about.html　關於藝術家（生平、年表、經歷）
- works.html　作品集圖庫（文字型圖庫，CSS 佔位塊）
- exhibitions.html　展覽與歷程
- publications.html　著作與藝評
- contact.html　聯絡（訂製・諮詢・LINE）

## REPLACE 替換點（正式上線前）
- REPLACE-LINE → 真實 LINE ID（https://line.me/R/ti/p/<ID>）
- REPLACE-EMAIL@example.com → 真實聯絡 Email
- REPLACE-PHONE → 真實聯絡電話
